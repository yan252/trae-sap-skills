# Clean ABAP Skill

This skill checks ABAP code for compliance with Clean ABAP principles based on SAP's Clean ABAP style guide.

## Keywords

clean-abap, clean code, abap, code review, code quality, best practices, abap code analysis, abap validation, abap check, clean abap principles, abap naming conventions, abap refactoring, abap standards

## Usage

Use this skill when:
- Checking ABAP code for clean code compliance
- Reviewing ABAP code quality
- Validating ABAP against best practices
- Analyzing ABAP code for improvements
- Refactoring ABAP code
- Following Clean ABAP guidelines
